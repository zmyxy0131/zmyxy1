# Fisher-Effect Real Interest Calculator Skill
> 货币银行学课程专属 Skill，用于演示**费雪效应**，计算名义利率、实际利率与通胀之间的关系

## ✨ 功能介绍
根据费雪方程式：
$$ 1+i = (1+r)(1+\pi^e) $$
- $i$：名义利率
- $r$：实际利率
- $\pi^e$：预期通货膨胀率

支持三种计算模式：
1. 已知名义利率、预期通胀，求解**实际利率**
2. 已知实际利率、预期通胀，求解**名义利率**
3. 已知名义利率、实际利率，求解**预期通胀率**

> 课程用途：理解费雪效应，区分事前/事后实际利率，是利率理论经典考点，和货币乘数、银行资产负债表不重复。

## 📌 使用示例
输入：名义利率=4.5%，预期通胀=2.0%
输出：事前实际利率 ≈ 2.45%

## 📖 理论简述
费雪效应：长期下，名义利率会随预期通胀一对一调整，实际利率保持稳定。
这是货币银行学「利率」章节核心内容。
